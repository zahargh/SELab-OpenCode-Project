# آزمایش ۲ — مروری بر اصول طراحی شی‌گرا

این ریپازیتوری شامل دو نسخه از پروژه است:

## ساختار پوشه‌ها

- **`01-OOD-Principles-Without/`** — نسخه‌ی اولیه‌ی پروژه پس از افزودن
  قابلیت «پرداخت نقدی»، بدون اصلاح نقض‌های اصول `SOLID` (گام ۱ و ۲
  آزمایش).
- **`02-OOD-Principles-Applied/`** — نسخه‌ی بازطراحی‌شده‌ی پروژه پس از
  اصلاح تمام نقض‌های `SOLID` با استفاده از `OpenCode` (گام ۳ تا ۷
  آزمایش).

## گزارش کامل

گزارش کامل آزمایش، شامل تحلیل هر ۷ گام و ارزیابی عملکرد `OpenCode`، در
فایل `README.md` داخل هر یک از دو پوشه‌ی بالا آمده است (هر دو پوشه دارای
یک نسخه‌ی یکسان از گزارش کامل هستند).
